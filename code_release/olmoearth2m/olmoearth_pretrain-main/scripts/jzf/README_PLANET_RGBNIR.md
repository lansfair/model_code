# Planet RGBNIR 超分辨率生成工具

## 概述

这个脚本 `generate_planet_rgbnir.py` 用于从H5文件中读取10m分辨率的RGB图像(通常来自Sentinel-2 L2A),使用双三次插值进行超分辨率处理,生成planet_rgbnir模态并保存回H5文件。

## 功能特点

- ✅ 从H5文件读取Sentinel-2 L2A数据
- ✅ 提取RGB波段(B04, B03, B02)
- ✅ 使用双三次插值进行超分辨率(从10m到~3m)
- ✅ 支持gzip和zstd压缩
- ✅ 自动处理缺失值(MISSING_VALUE)
- ✅ 支持单文件和批量处理
- ✅ Dry run模式(只读不写)
- ✅ 详细的日志输出

## 使用方法

### 处理单个H5文件

```bash
python generate_planet_rgbnir.py \
    --h5-file /path/to/sample_12345.h5 \
    --log-level INFO
```

### 处理整个目录

```bash
python generate_planet_rgbnir.py \
    --h5-dir /path/to/h5py_dir/ \
    --compression zstd \
    --compression-opts 3 \
    --log-level INFO
```

### Dry Run模式(测试用,不写入)

```bash
python generate_planet_rgbnir.py \
    --h5-dir /path/to/h5py_dir/ \
    --max-files 5 \
    --dry-run \
    --log-level DEBUG
```

### 限制处理文件数量

```bash
python generate_planet_rgbnir.py \
    --h5-dir /path/to/h5py_dir/ \
    --max-files 100
```

## 工作原理

### 1. 数据读取

从H5文件中读取指定源模态(默认`sentinel2_l2a`)的数据:
- 形状: `(H, W, T, C)` - 高度、宽度、时间步、通道数
- Sentinel-2 L2A包含12个波段

### 2. RGB提取

从Sentinel-2波段中提取RGB:
- R (Red) = B04 (索引2)
- G (Green) = B03 (索引1)  
- B (Blue) = B02 (索引0)

### 3. 超分辨率

使用OpenCV的双三次插值(`INTER_CUBIC`)进行上采样:
- 根据源和目标模态的tile size计算缩放因子
- 对每个时间步独立进行超分辨率
- 保持数据类型不变

### 4. 数据写入

将超分辨率后的RGB数据作为新模态写入H5文件:
- 数据集名称: `planet_rgbnir`
- 支持zstd和gzip压缩
- 自动验证写入结果

## 注意事项

### ⚠️ 重要提示

1. **备份数据**: 脚本会修改原始H5文件,建议先备份重要数据
2. **磁盘空间**: 超分辨率后数据量会增加约11倍(3.33² ≈ 11)
3. **处理时间**: 大文件或大批量处理可能需要较长时间
4. **内存使用**: 处理过程中会加载完整数据到内存

### 🔧 自定义超分辨率算法

- ESRGAN
- Real-ESRGAN
- SwinIR
- 其他深度学习超分模型

示例:

```python
    # 使用深度学习模型进行超分辨率
    # ...
    return rgb_hr
```

### 📊 性能优化

对于大批量处理:
1. 使用`--max-files`分批处理
2. 考虑并行处理多个文件
3. 使用SSD存储提高I/O性能
4. 监控内存使用情况

## 故障排除

### 问题1: 找不到源模态

```
WARNING - Source modality 'sentinel2_l2a' not found in sample.h5
```

**解决**: 检查H5文件中实际存在的模态名称:
```bash
python inspect_h5.py /path/to/sample.h5
```

### 问题2: 内存不足

**解决**: 
- 减少同时处理的文件数量
- 增加系统内存
- 使用较小的测试数据集

### 问题3: 压缩错误

```
Error: Unsupported compression: xxx
```

**解决**: 确保使用了支持的压缩算法(`gzip`或`zstd`)
